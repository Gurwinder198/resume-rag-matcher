# Resume RAG & Job Matcher

A RAG pipeline over resumes (section-aware chunking, local embeddings,
ChromaDB) and a hybrid semantic+keyword job-matching engine.

## Setup (Windows)

```powershell
.\setup.bat
```

Manual equivalent:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
copy .env.example .env   # only needed for --use-llm-reasoning
```

The first run that touches `vector_store.py` downloads the
`all-MiniLM-L6-v2` embedding model (~90MB) from Hugging Face Hub — needs
internet once, then cached under `~/.cache`.

## Dataset

`resumes/` (32 synthetic resumes across 8 roles), `job_descriptions/` (5 JDs),
and `dataset_manifest.json` (ground truth) were generated by:

```powershell
.\.venv\Scripts\python.exe scripts\generate_dataset.py --out-dir .
```

## Part A — Ingest resumes into the vector store

```powershell
.\.venv\Scripts\python.exe resume_rag.py --resumes-dir resumes --persist-dir chroma_db
```

## Part B — Match a job description

```powershell
.\.venv\Scripts\python.exe job_matcher.py --job-description-file job_descriptions/jd_ml_engineer.txt --top-k 10
.\.venv\Scripts\python.exe job_matcher.py --job-description-file job_descriptions/jd_ml_engineer.txt --use-llm-reasoning
```

`--use-llm-reasoning` calls OpenRouter (set `OPENROUTER_API_KEY` in `.env`) to
generate the `reasoning` text; without it, a template-based reasoning string
is used (no API key needed).

## Notebook

`notebooks/rag_experimentation.ipynb` — ingestion, chunking inspection,
precision@5 per job description (against `dataset_manifest.json` ground
truth, measured on the unfiltered ranker — no must-have hard filter — so it
scores the semantic+keyword ranking itself), and latency. On the generated
dataset it measured **precision@5 = 0.4 for every job description** (2 of
4 same-role resumes land in the top 5 of 10 ranked candidates, with the true
matches scoring ~30 points above the next-best candidate) and **~20ms mean
match() latency**. Regenerate with:

```powershell
.\.venv\Scripts\python.exe scripts\build_notebook.py
.\.venv\Scripts\python.exe -m jupyter execute notebooks\rag_experimentation.ipynb --output rag_experimentation.ipynb
```

## Demo

## Architecture

| Module | Responsibility |
|---|---|
| `fs_tools.py` | File loading (ported from Milestone 1) |
| `chunking.py` | Section-aware chunking |
| `metadata_extractor.py` | Name/Skills/Experience Years/Education extraction |
| `vector_store.py` | ChromaDB + local sentence-transformers embeddings |
| `resume_rag.py` | Part A — ingestion pipeline |
| `job_matcher.py` | Part B — hybrid search, scoring, filtering, reasoning |
| `metrics.py` | precision@k, latency |
| `scripts/generate_dataset.py` | Synthetic dataset generator |
| `scripts/build_notebook.py` | Notebook generator |
